# 初回実装 要求内容 (requirements)

**作業ID:** 20260523-initial-implementation
**日付:** 2026-05-23

## 目的

ペロブスカイト系材料（特にハライドペロブスカイト）の電子バンド構造を、
タイトバインディング (TB) / Slater-Koster 法で計算する Python プログラムを構築する。
**論文に記載のアルゴリズムとパラメータを厳密に再現する**ことを最優先とし、
**ハルシネーションを絶対に許さない**。

## 機能要求

1. **モデル**: `references/pdfs` の論文から、TB アルゴリズムとパラメータが明示された
   ものを選定して実装する。初回は以下を対象とする:
   - Kashikar, Gupta, Nanda (arXiv:2101.08562): 立方晶 CsBX₃ (B=Ge/Sn/Pb, X=Cl/Br/I)
     の 13軌道 / 4軌道 Slater-Koster モデル。
   - Nestoklon (arXiv:2012.14705): 立方晶 CsPbI₃ の sp³ / sp³d⁵s\* 経験的 TB。
2. **入力**: 材料・パラメータ・k 経路はすべて **JSON で入力**する。
3. **出力**: バンド構造（高対称点を通る経路上の固有値）と図、バンドギャップ。
4. **再現性**: 使用した物性値（パラメータ）を出典付きで保管し、いつでも再現できるようにする。
   計算結果には実行条件メタデータ（コミットハッシュ・パラメータ・日時）を付与する。

## 受け入れ条件（V&V）

論文に明示された数値を許容誤差内で再現すること:

- **Kashikar 13軌道**: R点 (π/a,π/a,π/a) で対角化した固有値が、論文の解析式 Eq.(9) と
  機械精度（< 1e-9 eV）で一致すること（全9材料）。
- **Kashikar 4軌道**: SOC なしのバンドギャップ閉形式 `Eg = εp-εs-2tppσ-4tppπ+6tss`
  と数値対角化が一致すること。
- **Nestoklon sp³ / sp³d⁵s\***: R点のバンドギャップが DFT 値 **1.017 eV** を、
  実験補正セットが R点 **1.65 eV** / M点 **2.75 eV** を、それぞれ妥当な許容誤差で再現すること。
  伝導帯の SO 分裂（R点）が **1.48 eV** 程度になること。
- 立方晶ハライドペロブスカイトの **直接ギャップが R 点に現れる**こと。

## 制約

- 浮動小数点の等価比較は禁止（許容誤差を用いる）。
- パラメータは論文記載値を改変せず転記（誤植が疑われても注記のみ）。
- 大容量データ（PDF 群）は Git 本体にコミットしない。
- こまめに commit & push し、進捗を `RESULTS.md` に反映する。
