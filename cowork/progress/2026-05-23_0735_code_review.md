## 質問 1 への応答：方法選択（k·p / Roth-Lax をバルク主手法とする）

**判定: 賛成（その方針で OK）**

理由：
- バルク9材料スキャンの主目的は「未測定の Ge/Sn 系 g_e, g_h を予測すること」。これはバンド端の局所物理なので、k·p / Roth-Lax で十分かつ妥当
- 速度行列要素ベースの計算は既存 Hamiltonian builder と整合性が良く、純拡張で済む
- Peierls+Zeeman 法は計算コストが高い（有限磁場 × k 点 × 対角化）。バルクスキャンには過剰

**推奨実装順:**
1. **Step A2-1:** k·p 普遍式（Eq.5, Eq.6）を `g_factor.py::g_kp_universal(Eg, Delta, p, dge)` として実装。**これがゴールドスタンダード**として A3 のテストアンカーに使う
2. **Step A2-2:** Roth-Lax を `compute_g_factor_roth_lax(H, v_ops, band_idx)` として実装。バンド間和は **モデル内の全バンド**で取る（remote 寄与は §3 の判断ポイントで議論済み通り、不完全になる可能性を認識した上で）
3. **Step A2-3:** CsPbI₃ で k·p と Roth-Lax を比較。差分が remote band 効果の指標になる

Peierls+Zeeman 法は **Theme A 完了後、ナノ結晶への拡張時に別 Phase で**実装してください。今は実装しなくて良い。

## 質問 3 への応答：Roth-Lax remote band / 符号規約

**判定: 実装方針 OK。以下の検証を A3 に追加してください**

### Remote band 寄与の取りこぼしについて

Nestoklon の Δg_e = −1（普遍パラメータ）は確かに「sp³d⁵s\* の外にある CB の更に上のバンド群」の寄与。TB モデル内の有限バンド数では完全には再現できません。

**対処方針:**
- Roth-Lax 計算結果（モデル内 N バンド和）と k·p 普遍式（Δg_e = −1 を入れた）の **差分** を「remote contribution」と定義し、各材料で記録
- 報告書では「TB モデルは sp³d⁵s\* で完結、残差 ≈ -1 は higher conduction bands による」と明示
- これは欠陥ではなく **科学的に正しい解釈**。論文化の際の議論ポイントにできる

### 符号規約・スピン寄与・Kramers 二重項

Roth-Lax 1959 の原典に従う（Cowork で再確認しました）：

```
軌道 g テンソル: Δg_{αβ} = (2/(i m₀ ℏ)) Σ_{n≠n₀} [<n₀|p_α|n><n|p_β|n₀> − (α↔β)] / (E_{n₀} − E_n)
スピン寄与: g_s = g₀ ≈ 2.0023 (free electron)
合計 g テンソル: g_{αβ} = g_s δ_{αβ} + Δg_{αβ}
```

立方対称では `g_αβ = g_iso δ_αβ` になるはず。Kramers 二重項の中で 2x2 磁気モーメント行列を作る場合、対角化して得られる 2 固有値が ±g_iso·μ_B·B/2。

**実装上の注意:**
- 速度演算子 `v_α = (1/ℏ)∂H/∂k_α` を使う場合、`p_α = m₀ v_α` の対応関係に注意
- `<n|p_α|m>` の Hermiticity は H が Hermitian なら自動的に保証されるが、∂H/∂k の解析微分で複素位相の取り扱いを慎重に
- スピン依存ホッピング（SOC）がある場合、∂H/∂k はスピノル基底のまま使う

## 質問 4 への応答：SOC→0 テスト設計

**判定: 質問の通り「孤立バンドで」検証する方針 OK。具体的設計を提案します**

### 推奨テスト設計

```python
def test_g_factor_free_electron_limit():
    """
    SOC = 0 かつバンド間混成が無視できる状況で g_orbital → 0、g_total → g₀ = 2.0023。
    
    実装: Kashikar 13軌道の lambda_so = 0 にし、さらに p 軌道だけ抜き出した
          孤立バンド（s だけ、または d だけ）を作って g を計算する。
    """
    H_isolated_s_band = make_isolated_s_band_hamiltonian()  # 結合なしの s バンド
    v_ops = compute_velocity_operators(H_isolated_s_band)
    g = compute_g_factor_roth_lax(H_isolated_s_band, v_ops, band_idx=0)
    assert abs(g['g_iso'] - 2.0023) < 1e-3
```

### 補足テスト

CsPbX₃ の CBM は Γ⁶⁻（s 的）で **bare 軌道角運動量寄与は本来ゼロ**ですが、Roth-Lax 経由で計算すると −2/3 のような有限値が出ます。これは「他バンドとの混成による有効値」であり、自由電子極限のテストとは別の物理。

→ テスト名で区別：
- `test_g_free_electron_limit` — バンド間混成 OFF（人工的）
- `test_g_cubic_perovskite_bare` — CBM 単独で SOC=0 にしたとき、−2/3 が出ることを確認（Kirstein 2021 が指摘）

これで両方の物理を区別できます。
