## 2. 主結果（鉛フリー g_h 普遍関係破れ）の物理的レビュー

### 物理的妥当性 ✅

報告書 §5 の考察「Pb の重い SOC が Sn/Ge で大幅減 → g_h 補正項が小さく g_h→+2 寄り」は **数式から自明に正しい**。

`g_h = 2 − (4/3)P²/C · [1/Eg − 1/(Eg+Δ)]`

の補正項は `Δ → 0` で **完全に消滅**（1/Eg − 1/Eg = 0）。Sn/Ge の Δ が小さければ g_h は +2 に近づく。物理的にこれ以上クリアな主張は無い。

### 数値のサニティチェック（独立計算）

CSV の数値を一部紙計算で検証：
- **CsPbI₃** (Eg=1.73, Δ=1.258): g_h = 2 − (4/3)(6.8²/7.62)·[1/1.73 − 1/2.988] = 2 − (4/3)(6.067)(0.578−0.335) = 2 − 1.963 = **+0.037** ≈ CSV 0.031 ✅
- **CsSnI₃** (Eg=1.30, Δ=0.42): g_h = 2 − 8.089·[1/1.30 − 1/1.72] = 2 − 8.089·(0.769−0.581) = 2 − 1.52 = **+0.48** = CSV 0.48 ✅
- **CsGeI₃** (Eg=1.60, Δ=0.21): g_h = 2 − 8.089·[1/1.60 − 1/1.81] = 2 − 8.089·(0.625−0.553) = 2 − 0.58 = **+1.42** = CSV 1.413 ✅

→ 計算は正確。

### 「乖離」の定義についての提案

報告書では「Pb 普遍曲線から +1.86 上方乖離」と書いていますが、これは **「全材料に universal Δ=1.5 を使ったときの値と、材料固有 Δ を使ったときの値の差」** ですね。

論文化の際は、この定義を **より明確に**：

> "We define the **deviation Δg_h = g_h(material-specific Δ_B) − g_h(universal Δ ≈ 1.5)** as a measure of how strongly the lead-free conduction-band SOC pulls the hole g-factor away from the Kirstein universal trend (which implicitly assumes Δ_Pb ≈ 1.5 eV)."

この定義を明示すれば「Pb 系で確立した普遍則が Sn/Ge では破れる」という主張が **絶対に誤解されない**。

## 3. 限界・要追加分析（論文化に向けて）

### 3.1 ⚠️ CsPbI₃ g_h の絶対値ズレ（要対応）

報告書 §4 にある通り、CsPbI₃ で g_h_materialDelta = +0.031 vs Nestoklon Table S2 = −0.33。**0.36 のズレは無視できない**。

仮説：
- **2バンド k·p の限界**: 報告書も指摘。Nestoklon は SI で多バンド補正を入れている可能性
- **Eg の値が違う**: 文献 Eg=1.73 vs Nestoklon が使用した 1.652
- **P の値が違う**: 普遍 P=6.8 vs Nestoklon の材料別 P

検証手順:
1. **Nestoklon SI Eq.(S3) の正確な形を読み直す**（remote 補正項が入っていないか）
2. **Eg = 1.652** で計算してみる → CsPbI3 g_h はどうなるか
3. **P_material from TB velocity** を計算してみる → どうなるか

`progress/.../「行き詰まったこと」` ではなく、A5 補強として実施してください。30 分の追加調査で良い。

### 3.2 g_e 普遍性の検証（次段階）

「全 9 材料が一本の曲線に乗る」は **P = 6.8 普遍を仮定**した帰結。これも検証必要：

- TB Hamiltonian から `P_material = (m₀/ℏ) · ⟨CBM|v_z|VBM⟩` を計算
- 9 材料の P を散布図に
- もし P が大きく違うなら、g_e の「単一曲線」は仮想的なものになる

これは A5 ではなく **Phase 1.5 / 拡張 A6** として実施推奨。
