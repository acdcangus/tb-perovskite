  Nestoklon Eq.S1b の `sin(θ) = √(1/3)` は cubic CB Bloch 構造の解析的帰結なので、

- **bare P の系統的過小評価**: Kashikar13 (4.1〜5.9) < Nestoklon sp³d⁵s\* (5.44) <
  Kirstein 普遍 (6.8) の階段構造は予測通り。**band-fit パラメータは g-fit ではない**
  という説明はそのまま論文の Methods に書ける品質。

## 3. Phase 1.5 B1-B3 個別評価

### `src/perovskite_tb/optical.py` ✅

- **`PI_E2_OVER_EPS0 = π·(4π·14.39964) = 568.41 eV·Å`** の数値が e²/(4πε₀)=14.39964 eV·Å
  と consistent。次元解析 OK（[ε_i] dimensionless: `(eV·Å) × (eV·Å)² × (1/eV²) ×
  (1/eV) / Å³ = 1`）。
- **`1/E_cv²` をループ内（遷移エネルギーで評価）に置く**判断が物理的に正しい。
  「ω 外側に出すと sub-gap で 1/ω² 偽 tail が出る」というコメントは、まさに
  Apergi 2023 で議論されている独立粒子近似での Lorentzian smearing の落とし穴を
  正確に回避しています。
- **スピンメジャー基底でスピン因子 2 を入れない**判断、明示されていて良い。
- **Lorentzian smearing**: η=0.05 eV はデフォルトとして妥当。

### `optical.py::_kramers_kronig` の数値積分（コメント1件）

現在の実装はマスク `|denom| > 1e-12` で極を**スキップ**して台形則しているのに
近い形ですが、Cauchy 主値の数値計算としてはこれは**「対称 cancellation 仮定」**
に依存します。等間隔 ω グリッドであれば pole の左右で対称 cancellation が
うまく働くため `eps_r > 1` を満たす形で計算できていますが、**B4 の収束テスト
の中で「ω グリッドが密になるほど KK 自己整合の誤差が縮む」ことだけは plot で
確認**してください（5%以下に収まっていれば論文化 OK）。

オプション改善（必須ではない）:

各 Lorentzian の Hilbert 変換は解析的に
`real part = (1/π) (E_cv - E) / ((E_cv - E)² + η²)` で書けるので、
和を取る前に解析的に KK 変換してから k 和を取れば数値誤差が消えます。
将来 Sipe-Shkrebtii の shift current でも同じ trick が要るので、Theme F 着手前に
分離した `kk_analytic` 関数を作っておくのが理想です（今はやらなくて OK）。

### `tests/test_optical.py::test_f_sum_rule_tb_incomplete`

- 0.05 < ratio < 0.6 で記録する設計は **「数値を強制せず物理現象として記録する」**

## 4. 判断ポイントへの応答（重要）

### (1) 「Blount 1962 の不完全性を論文の手法論ポイントとして明記する方針」→ **強く支持** ✅

これは Theme A 論文の中心メッセージとして極めて強力です。**g 因子の Roth-Lax
過小評価** と **光学 f-sum の ~20% 取得** が**同じ原因（TB velocity operator =
`dH/dk` は intra-atomic 電流を欠く、Blount 1962, Phys. Rev. 126, 1636）から
出てくる**ことを明記すれば、論文として：

- **方法論の一貫性**: 同じ TB Hamiltonian + 同じ velocity operator が、g 因子も
  光学応答も同じレベルで「相対量・形状は信頼可、絶対量は系統的過小」を示す。
- **既知の理論的限界の再発見と定量化**: 単なる主張ではなく、9 材料 × 複数
  軌道基底での定量検証として提示できる。
- **Wannier ベースへの展開動機**: 「正確な absolute 値が要れば Wannier interpolation
  で position operator を陽に扱う必要」と将来 work を自然に提示できる。

論文化時の推奨文言（**Methods or Discussion**）：

> "Our TB results display two systematic underestimates: the Roth-Lax g-factor
> from `dH/dk` is ~3× too small relative to the k.p formula, and the optical
> f-sum rule is satisfied at only ~20%. Both originate from the same source:
> the velocity operator in a localized basis, `v ~ dH/dk`, omits the
> intra-atomic position-matrix contribution famously discussed by Blount
> (Phys. Rev. 126, 1636 (1962)). Our paper therefore emphasizes *relative*
> trends across materials and *spectral shape* / *band-edge* features, both
> of which we show are robust under this limitation, while keeping absolute
> magnitudes as documented diagnostics rather than as predictions."

**追加依頼:** `docs/optical-formulation.md` と `docs/g-factor-formulation.md`
の両方に **Blount 1962, Phys. Rev. 126, 1636 を共通参考文献として明示引用**
してください。Theme A 報告書 §4 にも既に「Blount 1962」と書かれていますが、
DOI または書誌情報 (Phys. Rev. 126, 1636 (1962)) を必ず添えること。
