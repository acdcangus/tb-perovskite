  単調収束。これは TB-IPA の Lorentzian 平滑化と離散 k サンプリングの帰結として
  期待通り（k 細分化で δ 関数化、broadening η だけ apparent edge がシフト）。

  明記できる強い証拠です。
- **η の役割**: peak 位置 (~4.10 eV) が η に対し安定で、apparent edge のみ ~η だけ
  シフトする挙動は Lorentzian 平滑化の数学的性質と整合（OK）。

## 4. A7（g_e 普遍性 inverse-P チェック）個別評価

### 物理の正しさ ✅（注釈付き）

`scripts/plot_ge_universality.py` の `_inverse_P()`:

```
P_inv = √[(g_e + 2/3 − δg_e) · (ℏ²/m₀) · E_g / (4/3)]
```

これは Kirstein 2021 Eq.(5) の `g_e = −2/3 + (4/3) (m₀ P²/ℏ²) (1/E_g) + δg_e` を
`P` について解いた式で、**符号・係数すべて正しい**（独立計算で照合済み）。

### 結果の意味（コミットメッセージにも明記されていて誠実）

- **Pb Table-S2 g_e から逆抽出した P が 3 ハロゲン共に 6.80**: これは Table S2 自身
  が **Kirstein の普遍 P=6.8 と整合的**な値であるため、半ば自己無撞着な確認
  （**semi-circular**, コミットメッセージで自己申告済み）。
- **TB-derived P が 25-40% 過小**: こちらは**非自明な結論**で、Blount 不完全性が
  P にも現れていることを示す独立証拠。Theme A の g 因子過小評価・光学 f-sum 不足と
  **同根の TB position operator 問題**として論文 §5 で統合議論できる。
- `reports/theme_A_g_factor.md §3.4` への追記（A7 述部 + semi-circular の注釈）も
  誠実で公開クオリティ。

### 小コメント（任意）

論文 Fig 化する場合、現在の `ge_universality.png` は **inverse-P の constancy が
直接見えない**（プロットされているのは g_e vs 1/Eg のみ）。論文 Fig.4 (案) として、
**2 段プロット**にすると最強です:
- 上段: 既存の g_e vs 1/Eg 図（universal P 線 + TB-P 散布 + Pb Table-S2 □）
- 下段: P vs E_g の棒グラフで「inverse-P (Pb 系のみ)=6.80 一定 / TB-derived P=4-6
  ハロゲン依存」を直接示す

これにより「普遍 P 仮定の自己無撞着性」と「TB-derived P の系統的不足」が同時に
読み取れます。**今は強制しません**（論文ドラフト着手時に検討）。
