## 1. Abelian discrete link の何が間違っているか — 物理的説明

現コード（`shift_current.py` L186-202）の loop:

```
loop = M(k)*ᵐᵛᶜ · M(k+dk)ᵥᶜ · Ov[c,c] · Ov[v,v]*
R_z  = -arg(loop) / dk
```

ここで `Ov[c,c] = ⟨u_c(k+dk)|u_c(k)⟩` は **U(1)** link（バンドごとに 1 個の複素数）。

**SOC で全バンドが Kramers 二重縮退**（中心対称 + TRS なら全 k で、P4mm + TRS でも Γ-Z 軸上などで縮退）すると、`numpy.linalg.eigh` は縮退部分空間 {c, c'} 内で固有ベクトルを **任意のユニタリ U(2) で混合**して返します（k ごとに独立にランダム）。すると `⟨u_c(k+dk)|u_c(k)⟩` は隣接 k 同士で「異なる U(2) 回転後の同じ部分空間」を比較することになり、位相が暴れる（観測された R_z(+k)=123, R_z(-k)=3141 の異常値はこれが原因）。

正しくは:
- 縮退部分空間 V={v, v'}（Kramers 価電子ペア）、C={c, c'}（伝導ペア）に対し
- link を **2×2 行列** `L_C(k,k+dk)[i,j] = ⟨u_{c_i}(k+dk)|u_{c_j}(k)⟩` として定義
- loop も 2×2 行列のトレースに変える

これが (A) の非アーベル化です。具体形は §2 で示します。

ただし **(B) sum-over-states 方式の方が TB 実装には圧倒的に楽**で、Tan & Rappe 2016 / Passos 2018 の実装系列で標準的なので、**こちらを推奨**します（§3）。

## 2. 修正方針 A: 非アーベル Wilson link（縮退部分空間トレース）

### 2.1 連続式（Fregoso 2017 Eq.(A6)-(A7) + 縮退拡張）

Fregoso 2017 が示すように、**gauge-invariant な shift vector の形** は φ を陽に追わずに書ける:

$$
R^{a,b}_{nm} \,|r^b_{nm}|^2 = -\,\mathrm{Im}\!\left[\,r^b_{mn}\,r^b_{nm;a}\,\right]
\quad \text{(Fregoso Eq.A6)}
$$

ここで一般化微分（共変微分）

$$
r^b_{nm;a} = \partial_{k_a} r^b_{nm} - i\,(\xi^a_{nn} - \xi^a_{mm})\,r^b_{nm}
$$

縮退バンドでは $\xi^a_{nn}, \xi^a_{mm}$ は対角ではなく **部分空間内の非アーベルゲージ場**になり、`r^b_{nm};a` も V×C 行列に拡張されます。形式的には

$$
\sigma^{abb}(\omega) \propto \sum_{V,C} \int [dk]\, f_{VC}\,
\mathrm{Im}\,\mathrm{Tr}_{V\!,C}\!\left[\,r^b_{CV}\,r^b_{VC;a}\,\right]\,\delta(\omega_{CV}-\omega)
$$

ここで $\mathrm{Tr}_{V\!,C}$ は **価電子縮退群 V と伝導縮退群 C の上でのトレース**（U(N_V), U(N_C) gauge 不変）。

### 2.2 離散表式（U(2) Wilson link）

A4 グリッドで実装するなら:

1. 各 k で `_eig` を行い、固有値を昇順ソート → 縮退クラスタを **エネルギー差 < tol（例 1e-6 eV）**でグループ化（Kramers なら毎回 2-fold; SOC で偶発縮退があるなら 4-fold も）。
2. クラスタごとに **block 内固有ベクトル** `U_V (N×n_V), U_C (N×n_C)` を取り出す。
3. 隣接 k+dk で同じ手順 → `U_V', U_C'`。
4. **block link**:
   ```
   L_V = U_V'† U_V   # (n_V × n_V)
   L_C = U_C'† U_C   # (n_C × n_C)
   ```
5. **transition matrix** はもはやスカラーではなく行列:
   ```
   M_VC      = U_V†  (dH/dk_b) U_C        # (n_V × n_C)
   M_VC_prime= U_V'† (dH/dk_b)(k+dk) U_C' # (n_V × n_C)
   ```
6. **gauge-invariant loop**（U(N_V)×U(N_C) closed loop）:
   ```
   X = M_VC† · M_VC_prime · L_C · L_V†   # (n_V × n_V) ? いや (n_C × n_C)
   ```
   厳密には Wilson loop scalar:
   ```
   loop_scalar = det( M_VC† · M_VC_prime · L_C · L_V† )
   または     = Tr( same ) / n_V
   ```
   `det` は U(1) phase（Berry phase loop）を取り出すのに自然。
7. `R_z = -arg(loop_scalar) / dk`、`intensity = ||M_VC||_F²` または `Σ |M_VC[i,j]|²`（縮退対の全遷移を 1 個にまとめる）。

**注意:** 縮退クラスタ判定の tol は **数値的に重要**。Kramers 厳密縮退は |ΔE|~1e-14 eV、偶発縮退は ~1e-6 程度を見ておく。tol を間違えるとペアを取り損ねて再び破綻するか、または近接（非縮退）バンドを誤って融合する。

**実装の落とし穴:**
- 縮退クラスタの個数が k ごとに変わると、形状不整合で配列処理が面倒。最初に「常に全バンドを Kramers ペアにまとめる（n_orb*4*2 → ペア n_orb*4）」と仮定するのが Nestoklon 4-原子セル + SOC + 中心対称無し（δ>0）にも安全（P4mm + TRS は全 k で Kramers）。

## 3. 修正方針 B: velocity-gauge sum-over-states（**推奨**）

### 3.1 なぜ B が良いか

- **k 近傍参照が不要**（dk 微分が消える）→ Monkhorst-Pack グリッドだけで完結。
- **eigenvector の phase 任意性が消える**: r^a_nm を **velocity matrix element経由**で書くと、`r^a_nm = ⟨n|v^a|m⟩ / (iω_nm)` (n≠m) は phase が n,m で打ち消しあう演算子変換（Fregoso Eq.B5）で、固有ベクトル globally re-phase してもよい。
- **縮退が自然に切れる**: 同じ縮退クラスタ内 (ω_lm = 0) の中間状態 l は分母で除外される。
- Passos 2018 が velocity-gauge 公式を全 nonlinear σ に対して導出済（出典あり）。Tan & Rappe 2016 の実装系列もこちら。

### 3.2 連続式（Sipe–Shkrebtii / Aversa–Sipe 公式; Passos 2018 でも導出）

generalized derivative の **sum-over-states 表式**:

$$
r^a_{nm;b} \;=\; \frac{1}{\omega_{nm}}\!\left[\, r^a_{nm}\,\Delta^b_{mn} \;+\; r^b_{nm}\,\Delta^a_{mn} \,\right]
\;+\; \frac{i}{\omega_{nm}} \sum_{l \neq n,m}\!\left[\, \omega_{lm}\,r^a_{nl}\,r^b_{lm} \;-\; \omega_{nl}\,r^b_{nl}\,r^a_{lm} \,\right]
\tag{*}
$$

ここで
- $r^a_{nm} = v^a_{nm}/(i\omega_{nm})$ for $n\neq m$ （velocity から interband Berry connection を構成）
- $\Delta^a_{mn} = v^a_{mm} - v^a_{nn}$ （band velocity 差）
- $v^a_{nm} = (1/\hbar)\langle n|\partial H/\partial k_a|m\rangle$ （既存 `velocity.py` をそのまま使える）
- 和 $\sum_{l\neq n,m}$ で **ω_lm=0 または ω_nl=0 となる l は除外**（縮退ペアの片割れが自動的に飛ぶ）

この式は **Sipe & Shkrebtii 2000 PRB 61, 5337 Eq.(4.5)**（あるいは元の **Aversa & Sipe 1995 PRB 52, 14636 Eq.(39)**）が原典。Passos 2018 (`arxiv_1712.04924.pdf`) の Section II-B でも導出されています（covariant derivative の commutator 展開、Eq.13）。

### 3.3 σ^zzz の最終形

Fregoso 2017 Eq.(A6) と (*) を組合せて (b=a=z, 対角):

$$
\sigma^{zzz}_{\text{shift}}(\omega)
\;=\; -\frac{\pi e^3}{\hbar^2}\!\int\!\frac{d^3k}{(2\pi)^3}\,
\sum_{v\in\text{occ}}\!\sum_{c\in\text{unocc}}\,
\mathrm{Im}\!\left[\, r^z_{cv}\, r^z_{vc;z} \,\right]\,
\delta(\omega_{cv}-\omega)
$$

ここで $r^z_{vc;z}$ は (*) で計算（v→c は v=v, m=c, a=b=z）:

$$
r^z_{vc;z} = \frac{2\,r^z_{vc}\,\Delta^z_{cv}}{\omega_{vc}}
\;+\; \frac{i}{\omega_{vc}}\!\sum_{l\neq v,c}\!\left[\, \omega_{lc}\,r^z_{vl}\,r^z_{lc} \;-\; \omega_{vl}\,r^z_{vl}\,r^z_{lc} \,\right]
$$

（a=b=z なので最初の括弧は `r^z·Δ^z + r^z·Δ^z = 2 r^z·Δ^z`、$\Delta^z_{cv}=v^z_{cc}-v^z_{vv}$）

**Lorentzian smearing** で δ→1/π · η/((ω_cv-ω)²+η²)（既存実装と同じ）。

**Kramers 縮退の扱い:**
- 中間状態 l の和で **|ω_lv| < tol または |ω_lc| < tol は skip**。これで v→v' (Kramers パートナー) や c→c' は自動除外。
- 価電子・伝導バンドのペア (v,c) を全 v < n_occ, c ≥ n_occ で回す。**縮退ペアの両方を別々の (v,c) として扱って良い** — それぞれ寄与は有限の数値、最終的に Im[...] の符号で正しく和を取る。

### 3.4 δ=0 vanishing がなぜ自動成立するか

- 中心対称（δ=0）では H(k) と H(-k) がユニタリ等価 → 全バンド E(k)=E(-k)、v^z(k) と v^z(-k) は反対符号（z は奇）。
- $r^z_{cv}(k) \cdot r^z_{vc;z}(k)$ の **virtual 全和** は inversion 演算で `Im[...] (k) = -Im[...] (-k)` となり、k と -k の寄与が打ち消す（ε² 様の偶部分 |r|² と異なり、shift 部分は generalized derivative の奇成分が掛かるため）。
- 数値的には MP グリッドが (-k, k) ペアを対称に含めば exact 0。Γ-centered odd grid でも対称性は保たれる（既存 `monkhorst_pack(n_kpts)` がそうなっているかは要確認 → §5 のテストで cover）。

### 3.5 実装疑似コード

```python
def shift_current_zzz_v2(H_fn, dHdk_fn, a, n_occ, omega_grid,
                         n_kpts=8, smearing_eta=0.05, deg_tol=1e-6):
    from .optical import monkhorst_pack
    kred = monkhorst_pack(n_kpts)
    kcart = kred * (2.0 * np.pi / a)
    Nw = omega_grid.shape[0]
    sigma = np.zeros(Nw)

    for k in kcart:
        E, U = _eig(H_fn(k))
        dHz = dHdk_fn(k, 2)
        Vz = U.conj().T @ dHz @ U     # ⟨n|∂H/∂k_z|m⟩  =  ℏ v^z_{nm}

        Nb = E.shape[0]
        # r^z_{nm} = V^z_{nm} / (i (E_m - E_n))  for n≠m
        # i.e. r^z[n,m] = -i V^z[n,m] / (E_m - E_n)
        for v in range(n_occ):
            for c in range(n_occ, Nb):
                wcv = E[c] - E[v]
                if wcv < deg_tol:
                    continue
                r_vc = -1j * Vz[v, c] / (E[c] - E[v])
                r_cv = -1j * Vz[c, v] / (E[v] - E[c])
                Delta_z_cv = Vz[c, c].real - Vz[v, v].real  # band velocity (real)
                # generalized derivative r^z_{vc;z}
                gd = 2.0 * r_vc * Delta_z_cv / (E[v] - E[c])
                # virtual sum, skip degenerate partners
                for l in range(Nb):
                    if l == v or l == c:
                        continue
                    w_lc = E[l] - E[c]
                    w_vl = E[v] - E[l]
                    if abs(w_lc) < deg_tol or abs(w_vl) < deg_tol:
                        continue
                    r_vl = -1j * Vz[v, l] / (E[l] - E[v])
                    r_lc = -1j * Vz[l, c] / (E[c] - E[l])
                    gd += 1j * (w_lc * r_vl * r_lc - w_vl * r_vl * r_lc) / (E[v] - E[c])
                # NOTE: 上の Σ は a=b=z の対角ケース; (*) の表式そのままを z,z に流用
                integrand_im = (r_cv * gd).imag
                L = (smearing_eta/np.pi) / ((wcv - omega_grid)**2 + smearing_eta**2)
                sigma += integrand_im * L
    sigma /= kcart.shape[0]
    return sigma  # prefactor (-π e³/ℏ²) は最後にかける
```

**注:** 上記疑似コードは符号・定数の最終チェック必須（私の式変形を Claude Code 側で紙ベース確認してから commit）。特に
- `r^a_{nm} = v^a_{nm}/(iω_{nm})` の `i` の入り方、
- `Δ^a_{mn} = v^a_{mm} - v^a_{nn}` の符号、
- (*) 式の `1/ω_{nm}` 全体係数

は Sipe-Shkrebtii の原典で必ず付き合わせること（**Aversa & Sipe 1995 PRB 52, 14636 Eq.(39)** が一次ソース; PDF が無ければ追加収集を依頼してください）。Fregoso 2017 と Passos 2018 で間接確認は可能ですが、Aversa-Sipe が「generalized derivative」を導入した原論文なので最終的な符号と prefactor の典拠はそこです。

## 5. (A) Wilson link を選ぶ場合の追加メモ

もし sum-over-states が numerical noise（intermediate state truncation の打ち切り誤差）で安定しないなら (A) に戻る選択肢が残ります。その場合:

- 上記 §2.2 の Wilson link で実装
- **dk のサイズ**: `1e-3` (現状) は Brillouin zone 端で大きすぎる可能性。`2π/a / (10 * n_kpts)` 程度を目安に
- **link normalize**: `L_C /= |det(L_C)|^(1/n_C)` で U(N) part だけ残す手当てを入れると数値安定
- **block 同定 tol** は §2.2 注釈どおり

ただし (B) の方が Tan & Rappe / 標準的な BPVE TB 実装の系列に近く、validation も容易です。**(B) を第一選択**にしてください。
