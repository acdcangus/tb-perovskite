## 2. ★ Deep review findings（新規 6 件）

### R3-DEEP-1 ★ Theme F の "gap (eV)" 列の定義が PI 解説に欠落

- **PI_explained_theme_F.md L66-77** の表は "gap (eV)" 列を持つが、これは **Kashikar-13 + [001] δ=0.15 Å 極性変位下の R 点 N_OCC ギャップ**であり、Theme A の experimental Eg（literature 値）や Phase 1.5 の optical edge（δ=0）と**別量**。
- 実例（CsPbI₃ の 3 箇所での「ギャップ」）:
  - Theme F: gap@R = **0.63 eV**（TB Kashikar + δ=0.15）
  - Theme A: Eg = **1.73 eV**（experimental 文献値）
  - Phase 1.5: 吸収端 ≈ **1.79 eV**（TB Kashikar, δ=0, 12³ k-grid）
- MANIFEST.notes には *"gap is the R-point N_OCC gap (not guaranteed CBM-VBM for all materials)"* と明記あるが、**PI 向け解説には反映されていない**。
- 影響: PI が 3 つの「band gap」を同じ量と誤読しうる。
- **推奨**: PI_explained_theme_F.md 表ヘッダを **「TB gap@R (δ=0.15) (eV)」** に明確化＋脚注 1 行で「Theme A の experimental Eg・Phase 1.5 の optical edge とは別量」を補足。

### R3-DEEP-2 ★ PI_explained_overview.md L164 の ε∞=2.4 の出典・対比が曖昧

- 「CsPbCl₃ で bare ε_∞=2.4 を使うと E_b=273 meV」とあるが、この **2.4 は literature 値（PMC12757862 DFT TB09 LST）**であり、本研究の主結果 MP DFPT の **ε∞=3.64 → E_b=119 meV**（同じ bare ε∞ カテゴリ）とは別。
- PI 読者は「bare ε=2.4 → 273（4×過大）」と「bare ε=3.64 → 119（~1.5×過大）」のどちらが「主結果」か混乱する恐れ。
- **本質的な論点はどちらも妥当**: bare ε∞ で計算すれば全部過大（手法・LST/DFPT で散乱 2.4〜3.64）。これが「C' は MP DFPT で**単一手法 consistency** を確保した」根拠。
- **推奨**: L164 後ろに 1 行「（同じ bare ε∞ でも LST DFT TB09=2.4, MP DFPT=3.64 と手法で散乱。C' は MP DFPT 単一手法で defensibility を確保）」を補足。
