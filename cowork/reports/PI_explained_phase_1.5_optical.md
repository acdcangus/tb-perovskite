## 0. 30 秒サマリ
- **何を計算したか**: 各ハライドペロブスカイトが**光をどう吸収・屈折するか**を表す**誘電関数 ε(ω)**（光の振動数 ω の関数）を

- **デバイス応用**: 誘電関数＝太陽電池が太陽光をどれだけ捕まえられるか（吸収）・反射防止設計（屈折率）の基礎。
  さらに ε(∞)（高周波誘電率）は励起子計算の遮蔽の基礎データ（ただし Theme I では独立に Materials Project DFPT ε∞ を採用; Phase 1.5 値は将来利用検討）。

## 1. 物理的背景
### 1.1 誘電関数 ε(ω) とは（絵で）
物質に光（振動する電場）を当てると、中の電子が揺さぶられて応答する。その応答の強さ・遅れを表すのが誘電関数
ε(ω)=ε₁+iε₂。
- **虚部 ε₂(ω)**: その振動数の光をどれだけ**吸収**するか（電子がバンド間を飛び移る＝光を food のように吸う）。
- **実部 ε₁(ω)**: 光をどれだけ遅らせる/曲げるか。屈折率 n ≈ √ε₁。低周波極限 ε₁(0)=**ε(∞)** が「高周波誘電率」。
- **アナロジー**: ブランコ（電子）を周期的に押す（光）。押す速さ（ω）によって揺れの大きさ（吸収）が変わる。

### 1.2 なぜ重要か
太陽電池は光を吸って初めて発電する → ε₂(ω)（吸収）の立ち上がり＝**光学ギャップ**が効率を左右。屈折率は反射損失・
光閉じ込め設計に。ε(∞) は励起子結合の遮蔽の基礎（Theme I は実際は MP DFPT ε∞ を採用）。

### 1.3 なぜ TB か
9 材料の ε(ω) を軽量・再現可能に。限界（吸収総量の過小, §5）も honest に併記。

---

## 2. 何を計算したか
- **Kubo-Greenwood 公式**で ε₂(ω) をバンド間遷移（速度行列要素 ⟨v|∂H/∂k|c⟩）から計算（Apergi 2023 の式）。
- **Kramers-Kronig 変換**で ε₂ から実部 ε₁ を得る → ε(∞)=ε₁(0)。
- 吸収スペクトルの立ち上がり＝光学吸収端。**f-sum 則**（吸収を全周波数で積分すると電子数に等しくなるべき）で検証。

```mermaid

  A[TB バンド & 波動関数 9材料] --> B[速度行列要素 <v|dH/dk|c>]
  B --> C[Kubo-Greenwood で ε2(ω) 吸収]
  C --> D[Kramers-Kronig → ε1(ω), ε∞=ε1(0)]
  C --> E[f-sum 則で検証]
  D --> F[屈折率・光学ギャップ・ε∞]
```

## 3. 結果（`MANIFEST key_numbers` より）

| 量 | 値 | 意味 |
|---|---|---|
| ε(∞) CsPbI₃ | **3.46** | 高周波誘電率（屈折率 n≈1.86 相当） |
| ε(∞) CsPbBr₃ | 2.35 | |
| ε(∞) CsPbCl₃ | 1.46 | |
| CsPbI₃ 吸収端 | **1.79 eV** | 光学ギャップ（バンドギャップ ~1.73 eV とほぼ一致） |
| f-sum 比 | **0.21** | ★後述（過小評価の指標） |

### 3.2 物理的読み解き
- **ε(∞) は Cl→Br→I で増える**（CsPbCl₃ 1.46 < CsPbBr₃ 2.35 < CsPbI₃ 3.46）。ギャップが小さい（I 系）ほど電子が
  光で動きやすく、遮蔽（誘電率）が大きい——直観どおり。
- **吸収端 ≈ バンドギャップ**（CsPbI₃ 1.79 eV vs gap 1.73 eV）。光吸収が直接ギャップから立ち上がることを再現。
- ε(∞) の絶対値は TB では低めに出る傾向（後述の f-sum 過小と同根）。

### 3.3 ★ f-sum 則 = 0.21 が意味すること（honest）
f-sum 則は「吸収スペクトルを全部足すと電子の数に一致する」べき、という厳密な総和則。本計算では **0.21**（理想の 1
の約 1/5）。これは TB の速度演算子が**原子内成分を欠く**（Blount 1962）ため吸収強度が系統的に過小になる、という
**構造的限界**を定量化したもの。
→ **吸収スペクトルの形・ギャップ・材料間トレンドは信頼可、絶対的な吸収強度は過小**。g 因子（過小）・shift current
（過小）と**同じ Blount の糸**でつながる統一的な限界。

## 4. 何が新しいか
- 9 材料の ε(ω) を一貫 TB 枠組みで提供し、ε(∞)・光学ギャップを系統化。
- f-sum=0.21 を明示して **TB-IPA（独立粒子近似）の限界を定量化**——後続テーマ（Theme I の励起子遮蔽）が
  なぜ外部 ε を要するかの根拠を与える。

## 5. 限界と今後の課題
- **f-sum 過小（Blount 1962）**: 絶対吸収強度・ε(∞) は過小評価。→ Wannier ベース位置演算子で補正、励起子（電子-正孔
  相互作用）の取り込み（GW-BSE）で改善。
- key_numbers には現状 Pb 系 3 材料の ε(∞) のみ収録（9 材料の ε(ω) スペクトルは bundle 内）。Sn/Ge の ε(∞) bundle 化は今後。

## 6. 用語集
- **誘電関数 ε(ω)**: 物質が振動電場（光）にどう応答するか。虚部=吸収、実部→屈折率。
- **Kubo-Greenwood 公式**: バンド間遷移から吸収（ε₂）を計算する標準公式。
- **Kramers-Kronig 変換**: 吸収（虚部）から実部を復元する数学関係（因果律に基づく）。
- **f-sum 則（Thomas-Reiche-Kuhn）**: 吸収の全周波数積分が電子数に等しいという総和則。
- **ε(∞)（高周波誘電率）**: 低周波（イオン応答を除く電子のみ）の誘電率。屈折率²にほぼ等しい。
- **光学ギャップ**: 吸収が立ち上がる最小光子エネルギー（≈バンドギャップ）。
