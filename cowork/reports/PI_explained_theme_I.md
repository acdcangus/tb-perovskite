## 0. 30 秒サマリ
- **何を計算したか**: 9 材料について、(a) 電子・正孔の**有効質量**（結晶の中で電子がどれだけ「重く」振る舞うか）と、
  (b) **励起子結合エネルギー E_b**（光で生まれた電子と正孔が、水素原子のように引き合って結合する強さ）。
- **何が新しいか / 分かったこと**: 有効質量マップは信頼でき、Sn 系が最軽量。E_b は「文献の誘電率では過大評価される」
  という**方法論的な落とし穴**を発見し、Materials Project の一貫した DFPT 誘電率で相対トレンドを確定した。
- **デバイス応用**: E_b が大きい材料＝励起子が安定＝**LED で明るく光る**。E_b が小さい材料＝電子と正孔がほどけやすい＝
  **太陽電池で電流を取り出しやすい**。有効質量は移動度（電流の流れやすさ）を左右する基礎量。

## 1. 物理的背景
### 1.1 有効質量とは（絵で）
結晶の中の電子は、周りの原子と相互作用するため、真空中とは違う「動きにくさ」を持つ。これを**有効質量 m\***で表す
（真空の電子質量 m₀ の何倍か）。**バンド（エネルギー対運動量の曲線）の曲がり具合**で決まる: よく曲がる（鋭い谷）＝
軽い＝速く動ける、平ら＝重い＝動きにくい。
- **アナロジー**: ボールが谷の底にある。谷が急なら軽く敏感に転がり（小さい m\*）、緩やかなら鈍い（大きい m\*）。

### 1.2 励起子と結合エネルギーとは
光が電子を叩き上げると、抜けた跡（**正孔**, 正電荷）が残る。電子（−）と正孔（+）は**クーロン力で引き合い**、
水素原子のようなペア「**励起子**」を作る。これを引き離すのに要るエネルギーが**結合エネルギー E_b**。
- **大きい E_b**: ペアが固い → 再結合して光る → **LED 向き**。
- **小さい E_b**: すぐほどけて自由な電子・正孔になる → 電流に → **太陽電池向き**。
- 引き離しやすさは**遮蔽**（周りの誘電率 ε）で決まる。ε が大きいほどクーロン力が弱まり E_b は小さい。

### 1.3 なぜ TB か
有効質量はバンドの曲率から直接出る（TB が得意）。E_b は質量＋誘電率の簡単な式（Wannier-Mott）で見積もれる。

---

## 2. 何を計算したか
- **有効質量**: R 点（直接ギャップの場所）でバンドの曲率 `m*/m₀ = (ℏ²/m₀)/(d²E/dk²)` を 3 方向で。立方なので等方的。
- **E_b**: 水素様（Wannier-Mott）式 `E_b = (μ/m₀)/ε² × 13.6 eV`（μ は電子と正孔の換算質量）。
- **誘電率 ε**: ここが肝。文献の bare 誘電率では過大評価になるため、**Materials Project の DFPT 誘電率**（単一手法で
  9 材料分）を PI 提供の API キーで取得して使用（option C'）。

```mermaid
graph TD
  A[TB バンド 9材料<br/>Kashikar 2021 の13軌道 active basis] --> B[R点曲率 → m_e, m_h, μ]
  C[Materials Project DFPT ε∞<br/>API経由・単一手法] --> D
  B --> D[Wannier-Mott E_b=(μ/m0)/ε²·Ry]
  D --> E[9材料 E_b マップ（相対トレンド）]
```

## 3. 結果（主結果 = C' 8 材料マップ、校正点 = D' CsPbI₃）

### 3.1 有効質量マップ（`theme_I_effective_mass MANIFEST` より、信頼可）

| 材料 | m_e | m_h | μ（換算質量） |
|---|---|---|---|
| CsPbI₃ | 0.106 | 0.134 | 0.059 |
| CsSnI₃ | 0.035 | 0.025 | **0.015（最軽）** |
| CsGeI₃ | 0.111 | 0.100 | 0.053 |
| CsPbCl₃ | 0.237 | 0.225 | 0.116（最重） |

（全 9 材料は bundle CSV。立方対称どおり**等方的**、有限差分も収束。CsPbI₃ m_e=0.106 は文献 ~0.1–0.15 と整合。）

### 3.2 励起子結合エネルギー E_b（`theme_I_exciton_MP_DFPT MANIFEST`、MP DFPT ε）

| 材料 | ε∞ (MP DFPT) | E_b (meV) |
|---|---|---|
| CsPbCl₃ | 3.64 | 119（最大） |
| CsGeCl₃ | 3.64 | 99 |
| CsPbBr₃ | 4.21 | 57 |
| CsPbI₃ | 4.43 | 41 |
| CsGeI₃ | 5.69 | 22 |
| CsGeBr₃ | 6.55 | 19 |
| CsSnBr₃ | 5.91 | 12 |
| CsSnI₃ | 7.35 | **4（最小）** |

（8 材料; CsSnCl₃ は MP に誘電率なく除外。全数値 `theme_I_exciton_MP_DFPT MANIFEST`。）

- **読み解き**: E_b は **Cl 系で大（重い質量・小さい ε）→ LED 向き**、**Sn-I で最小（超軽量質量・大きい ε）→ 太陽電池向き**。
- **相対トレンドは defensible**（MP の単一手法 DFPT ε を使用）。

### 3.3 ★ 方法論的発見（honest）
- Wannier-Mott が要するのは励起子が感じる**実効遮蔽 ε_eff**だが、文献・DFPT が出すのは**bare（裸の）電子誘電率 ε∞**。
  ε∞ < ε_eff なので、**bare ε で計算すると E_b が過大評価**になる。
- 校正点 CsPbI₃: 本研究 μ=0.0592 と Cho 2019 の実効 ε=6.1 で E_b=**22 meV**（Cho 自身は μ=0.10 で 37 meV; 実験 7.4–50 meV, Cho 2019。ε=6.1 は 2D 無機層値で bulk 転用は近似）。MP の bare ε=4.43 だと
  41 meV（~2 倍過大）。→ **絶対値は上限、相対トレンドが頑健**、と正直に位置づけ。
- なぜ MP を使ったか: web 調査で「9 材料の一貫した ε は文献に散在・paywall・相不一致」と判明 → 単一手法（MP DFPT）で
  consistency を確保（PI 提供の API キー）。

## 4. 何が新しいか
- 9 材料の **TB 有効質量マップ**（信頼可）と、**Wannier-Mott E_b の系統比較**。
- **ε_eff vs bare ε の落とし穴**を定量化し、Materials Project DFPT で誤差源を分離（μ=TB / ε=MP）した hybrid 手法。
- **C' を主結果（8 材料の相対トレンド）・D' を校正点（CsPbI₃ で実効 ε による絶対値の実験整合）として併記する hybrid 提示**は、
  bare ε∞ の系統的過大評価を honest に扱いつつ実用的な material ランキングを与える、本研究の方法論的貢献。

## 5. 限界と今後の課題
- **bare ε → E_b 絶対値は上限**（過大）。実効 ε_eff（フォノン遮蔽込み）は CsPbI₃ 型しか文献にない。
- MP の DFPT 誘電率は一部材料で立方相でなく基底状態相（ortho/rhombo）由来（~相非依存 proxy として使用、相を明記）。
  CsSnCl₃ は MP に誘電率なしで除外。
- **改善**: 実験 ε_eff の収集、フォノン遮蔽の取り込み（Fröhlich/Pekar）、GW-BSE による直接励起子計算。

## 6. 用語集
- **有効質量 m\***: 結晶中の電子の「動きにくさ」。バンド曲率の逆数に比例。m₀=真空の電子質量。
- **正孔（ホール）**: 電子が抜けた空席。正電荷の粒子のように動く。
- **励起子**: 電子と正孔がクーロン力で結合した水素原子様のペア。
- **結合エネルギー E_b**: 励起子を電子と正孔に引き離すのに要るエネルギー。
- **Wannier-Mott 模型**: 励起子を水素原子に見立てた式 E_b=(μ/m₀)/ε²·Ry。
- **誘電率 ε∞（bare）/ ε_eff（実効）**: 前者は電子のみの遮蔽、後者はフォノン込みで励起子が実際に感じる遮蔽。ε∞<ε_eff。
- **DFPT / Materials Project**: 密度汎関数摂動論で誘電率等を計算する手法 / そのデータを集めた公開データベース。
