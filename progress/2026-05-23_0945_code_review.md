## A5 補強の評価

### CsPbI₃ g_h ズレ調査 ✅ 素晴らしい

切り分けが見事です：
- Eg=1.652 にすると 0.36 → 0.15 まで埋まる（半分は Eg 由来）
- 残差 0.21 は **「g_e 用 P と g_h 用 P が違う」**ことを発見（P_e=6.80 vs P_h=7.13）
- これは Nestoklon 2023 が SI で議論している **「P_h ≠ P_e で異方性的補正が必要」** という事実の再発見

これは **論文の物理考察で議論する価値あり**: 「Pb 系で P_h と P_e が ~5% 違うのは、価電子帯と伝導帯の対称性の違いから来る k·p の高次補正の現れ」。Sn/Ge で同じ違いがあるかは TB-derived P があれば検証できます（将来の A6 課題）。

主結果（相対乖離）が絶対値ズレに鈍感、という考察も的確。

## 判断ポイントへの応答（前因子・検証アンカー）

> 「光学の前因子は f-sum rule で校正、絶対強度の論文一致は二次、主検証は『吸収端=ギャップ』+ f-sum + KK 整合 とする方針で良いか」

### ✅ 基本方針 OK、ただし**実験ベンチマークを追加**してください

**理由:** 3D 無機立方 CsBX₃ の TB-based ε(ω) は確かに直接の論文アンカーが弱いですが、**実験値・DFT 計算値は豊富にあります**。Cowork でいくつか見つけました：

#### 推奨追加アンカー（実験＋DFT 文献値）

**(1) CsPbI₃ の吸収係数** （Cowork 文献調査結果）:
- 可視域で **α ≈ 10⁵ cm⁻¹**（複数 DFT 文献; 出典候補: ACS Omega 2021, DOI:10.1021/acsomega.1c00734 など）
- 直接ギャップ近傍で立ち上がり、~2 eV で 10⁵ オーダーに達する

**(2) CsPbI₃ の屈折率**:
- n(435 nm) ≈ 2.46（実験膜、DOI:10.1016/j.rinp.2018.10.024 等）
- 静的誘電率 ε_∞ ≈ 5-6（DFT）

**(3) CsPbBr₃ vs CsPbI₃ の相対関係**:
- 静的誘電率: CsPbI₃ > CsPbBr₃（DFT 一致）→ 本実装で同じ傾向が出るかチェック

これらを `tests/test_optical.py` の検証アンカーに加えてください（許容 ±50% で OK; TB-IPA は実験との絶対値一致は本来期待しない）。

#### 検証アンカー優先順位（推奨）

| 優先度 | 検証項目 | 許容 |
|---|---|---|
| 必須 | 吸収端 = TB バンドギャップ | ±0.05 eV |
| 必須 | 立方等方 ε_xx = ε_yy = ε_zz | 数値積分誤差 |
| 必須 | f-sum rule | ±5% |
| 必須 | KK 整合 (ε_r ↔ ε_i) | ±5% |
| 推奨 | CsPbI₃ α(可視) ~ 10⁵ cm⁻¹ | order of magnitude |
| 推奨 | CsPbI₃ n(可視) ~ 2-3 | ±30% |
| 推奨 | CsPbI₃ ε_∞ > CsPbBr₃ ε_∞ | 順序のみ |

これらを論文の Methods に書ければ「TB-IPA は絶対値は実験の範囲内、相対傾向は厳密に再現」というクリアな立ち位置になります。
