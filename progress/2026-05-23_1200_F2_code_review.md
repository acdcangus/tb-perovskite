## 1. 物理レビュー（精査）

### 1.1 §2 支配方程式

Sipe-Shkrebtii 2000 (PRB 61, 5337) の standard form と一致。係数 `-πe³/ℏ²`、`f_{nm}=f_n-f_m`、
`Im[r^a_{mn} r^b_{nm;c}]` の構造、δ(ω-ω_{nm}) の絶対値 conduction → valence indexing、すべて OK。

- Berry connection の definition `r^a_{mn} = i⟨m|∂_{k_a}H|n⟩/(E_n - E_m)` は **n≠m に限定**と
  明記されており正しい（intra-band は別の物理量）。
- `velocity.py` の `∂H/∂k` を **解析的**に再利用する方針は g-factor (Theme A) / 光学 (Phase 1.5)
  と完全に同じ pipeline で、エンジン拡張の最小化として理想的。
- δ → Lorentzian (η≈0.05 eV) は Phase 1.5 B5 / Theme A5 と同じ broadening 規約。一貫性 OK。

shift vector 形式 (Fregoso 2017) との等価性も §2 末尾に明示されており、F3 で両形式の
切り替え実装余地があるのは設計として柔軟。

### 1.2 §3 covariant derivative の数値スキーム

`r^b_{nm;c} = ∂_{k_c} r^b_{nm} - i(r^c_{nn} - r^c_{mm}) r^b_{nm}` は **gauge-covariant**（gauge を
固定すれば数値計算可能、結果は gauge-invariant の物理量）。Passos 2018 と Tan & Rappe 2016
Methods で標準。

- **(A) k 有限差分**を主、**(B) sum-over-states** を検証用とする選択は妥当。
  - (A) は **gauge 固定**が必須（隣接 k で固有ベクトルの位相を smooth 接続）。F3 実装時は
    parallel transport gauge を採用してください（Tan & Rappe 2016 Methods 参照）。
  - (B) は実装重いが gauge 自由で頑健。F4 cross-check で 1-2 材料で実施。
- `n=m` 除外は §3-4 で明記済み。OK。

### 1.3 §4 symmetry breaker（重要・Cowork directive 補正）

**Claude Code の指摘は完全に正しい。Cowork directive (1055) §1.2 の uniaxial strain 推奨を
撤回します:**

| 操作 | 結晶系 | 反転中心 | σ⁽²⁾ |
|---|---|---|---|
| 無歪み Pm-3m | cubic | あり (m-3m) | **= 0** |
| [001] uniaxial strain | P4/mmm tetragonal | **あり** (4/mmm) | **= 0**（依然消失） |
| [001] 極性変位 (Pb or Cs off-center) | **P4mm tetragonal** | **なし** (4mm) | **≠ 0** ✓ |
| octahedral tilt (非中心対称パターン) | 各種 | tilt パターン依存 | tilt 依存 |

F3 では **§4 (III) [001] 極性変位 δ ∈ [0, 0.3 Å]** を主 symmetry breaker としてスキャン
してください。これにより:

- δ=0 で σ⁽²⁾ ≡ 0（対称性厳密、anchor 1）
- δ>0 で σ⁽²⁾_{zzz}(ω) ≠ 0 が連続的に立ち上がる（anchor 2）
- 小 δ 領域で σ⁽²⁾ ∝ δ の線形応答（anchor 2 の細目）

の3点が一貫した検証ストーリーになる。**Tan & Rappe 2016 自体が強誘電 BaTiO₃ や極性化させた
MAPbI₃ で扱っている**ので、この選択は文献整合性も担保される（§5 anchor 4 で MAPbI₃ ピーク
照合する際に、Tan & Rappe の極性配置と同等の δ を選ぶ）。

**1点だけ補足:** "δ"（極性変位量）は Pb の halide cage に対する [001] off-set 距離（Å）として
明示してください。F3 の APIで `polar_displacement_z: float = 0.0`（Å、デフォルト 0 = 中心対称）
というキーワード引数にし、δ=0 が「無摂動 = 数値的に σ⁽²⁾=0 が出る」ことを単体テストで
保証してください。

### 1.4 §4 SK 距離スケーリング η_l（出典確定）

**Cowork 判断: Harrison η=2 を default 採用、感度は (η=1.5, 2.0, 2.5) で documented として OK。**

根拠:

- W. A. Harrison, *Electronic Structure and the Properties of Solids* (Freeman, 1980;
  Dover reprint 1989), Table 20-1 / Eq. (20-5): tight-binding hopping integral の
  universal distance scaling は `V_{ll'm}(d) = η_{ll'm} ℏ²/(m_e d²)`、すなわち **全ての s-p
  軌道対で d⁻²** が「Harrison の普遍値」。
- ハライドペロブスカイトの Kashikar 2021 / Nestoklon 2020 基底は **s,p のみ**（d 軌道なし）
  なので、d⁻² で良い（d⁻⁵ が要るのは d-d ホッピングで遷移金属の場合）。
- 材料別フィットは strained-DFT データが必要だが、現プロジェクト範囲外。**Harrison が
  普遍的・物理的に妥当な default**。F3 では η=2.0 を default、`scripts/` で η ∈ {1.5, 2.0, 2.5}
  の sensitivity を 1 材料（CsPbI₃ あたり）で 1 回回し、`results/shift_current/eta_sensitivity.md`
  に記録すれば十分。

実装上の API 提案:

```python
def slater_koster_strained_hopping(
    t0: float,           # 無歪み結合長 d0 での hopping (eV)
    d0: float,           # 無歪み結合長 (Å)
    d: float,            # 歪み後結合長 (Å)
    eta: float = 2.0,    # Harrison 距離スケーリング指数 (default = 2)
) -> float:
    """Harrison universal distance scaling: t(d) = t(d0) * (d0/d)^eta.

    Ref: W. A. Harrison, *Electronic Structure and the Properties of Solids*
    (Dover, 1989), Eq. (20-5). Default eta=2 is the universal value for
    s-p systems (no d-orbitals in Kashikar/Nestoklon basis).
    """
    return t0 * (d0 / d) ** eta
```

docstring に Harrison 出典を明記してください（CLAUDE.md「マジックナンバー禁止・出典明記」）。
