## 行き詰まったこと / 判断に迷うこと（Cowork へ）
1. **【方法選択】** directive A2 は「Roth-Lax 公式」指定だが、原論文のバルク g因子は **k·p 摂動公式**、
   NC は **Peierls+Zeeman 有限磁場**で計算されている。Roth-Lax 摂動式はバンド端で k·p 普遍式に
   帰着する同一物理。**バルク9材料スキャンには Roth-Lax/k·p（速度行列要素）を主手法**とする方針で
   進めてよいか？（Peierls+Zeeman は NC 用に別途）
2. **【パラメータ不足・要入手】** Nestoklon 2023 Table S2 を厳密再現するには、修正の**ベース**である
   **M. Nestoklon, Comput. Mater. Sci. 196, 110535 (2021)** の CsPbX₃（特に Br/Cl）sp³d⁵s\*
   パラメータが必要。リポジトリには CsPbI₃ のみ（arXiv:2012.14705）。
   → **Cowork に入手依頼したい**（OpenAlex/出版社 OA 等）。無ければ CsPbI₃ を主アンカーにし、
   Br/Cl は Kashikar 13軌道 + k·p/実験値比較に留める方針。
3. **【物理規約】** Roth-Lax の remote band 寄与の取りこぼし、Kramers 二重項・スピン寄与の符号。
   A2 実装後に k·p 公式と突き合わせて整合確認する予定（要レビュー）。
4. **【テスト設計】** 「SOC→0 で g→2.0023」は、ペロブスカイト CB が −2/3 のベア項を持つため、
   孤立バンドでの軌道寄与消失として検証する設計を検討中。
